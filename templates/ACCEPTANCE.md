## 3. 状态与异常

- [ ] 空数据（0 条）显示空态 + 引导按钮
- [ ] 加载中显示骨架屏/loading，不白屏
- [ ] 接口失败显示错误态 + 重试，重试可恢复
- [ ] 断网：提示明确，恢复网络后可继续
- [ ] 慢网（3s）：不卡死主线程，有反馈
- [ ] 401：跳登录并保留原页面意图
- [ ] 重复提交：只生效一次
- [ ] 超长文本 / 超长用户名：不破版
- [ ] 0 / 负数 / 超大金额：显示正确
- [ ] 快速连点：不进入错误状态
