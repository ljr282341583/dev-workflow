## 1. 风格定义

| 项 | 取值（示例） | 理由 |
| --- | --- | --- |
| 风格关键词 | 干净 / 可信 / 高信息密度 | 工具型产品，第一眼要"能算清账"，不要装饰感 |
| 参考对象 | — | |
| 主色 | #2563EB（trust blue） | 金融/记账类通用可信色；白字对比度约 5.2:1 |
| 主色可变体 | 深 #1D4ED8（按下/悬停）、弱 #EAF0FE（图标底/选中底） | 只用同一色相的明度变化，不引入第二种强调色 |
| 中性色阶梯 | 背景 #F4F6FB / 卡片 #FFFFFF / 描边 #E5E9F2 / 正文 #111827 / 辅助 #5B6473 | 用表面色差分层，不靠重阴影 |
| 语义色 | 成功 #0B7A45 / 警告 #A45A05 / 危险 #C42B21 | 各只一种，且都做过 4.5:1 对比度校验 |
| 字体 | 系统字体栈（中文）+ tabular-nums（数字） | 零网络依赖、包体最小；金额列必须对齐 |

## 2. 字号与排版阶梯

| 级别 | 字号 | 字重 | 行高 | 用在哪 |

| Display | 36 | 700 | 44 | 品牌名/首屏大标题（一屏最多 1 处） |

## 3. 间距 / 圆角 / 阴影

- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 40 / 48（8pt 栅格，相邻元素至少 8，区块之间 24～32）
- 页面左右内边距：16（全站统一）
- 卡片内边距：16；卡片间距：12
- 圆角：**8**（小控件/图标底）/ **12**（卡片、输入框）/ **20**（弹层、大容器）/ **胶囊**（按钮、chips、标签，即 999）——3 档 + 胶囊，不再加别的
- 阴影：**shadow-1** 卡片静置 / **shadow-2** 悬浮、分段控件 / **shadow-3** 弹层——恰好 3 档，彩色按钮不加辉光

## 4. 组件规范

| 组件 | 关键规格 | 状态 |
| --- | --- | --- |
| 主按钮 | 高 48，**胶囊**圆角，主色底白字，水平内边距 24 | 默认/悬停/按下/禁用/加载（危险操作用危险色） |

| 列表行 | 高 60（含图标），左图标 40×40 圆角 8 底 | 默认/按下/禁用 |

## 6. 动效

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 页面/屏切换 | 200ms（`--duration-200`） | ease-out | 位移 8–12px + 淡入，不用缩放 |
| 组件状态变化（分段控件、开关） | 150ms（`--duration-150`） | ease-out | 位置与颜色同步过渡 |
| 按下反馈 | 100ms | ease | scale 0.98 或背景加深一档，绝不 0ms |
| 骨架屏 | 1200ms 循环 | linear | 呼吸感，不闪烁 |
