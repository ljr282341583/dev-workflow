UI 优先开发流程 · 安装说明（小白版）
==========================================

三步，只需一分钟：

  第 1 步：把压缩包解压到任意位置（桌面就行）
  第 2 步：双击「安装.cmd」
  第 3 步：看到「安装结果」里全是 ✅ 就成功了，按任意键关掉窗口

装完你会看到类似这样：

  ================ 安装结果 ================
    ✅ DSH 技能已装
    ✅ DSH 全局红线已写入
    ✅ 工作区 §2.6 已接上
    ✅ Codex 技能已装
    ✅ Codex 红线已写入
    ✅ Claude 技能已装
    ✅ Claude 红线已写入
    🎉 全部就绪，以后不需要再装。

  现在对 AI 说一句就能用：
     「帮我做个 XXX 的 App」
  AI 会先问你需求 → 出 2~3 套 UI 方向给你选 → 你点「过」→ 它才开始写代码。
  ==========================================


装完之后怎么用？
--------------
对 AI 说一句「帮我做个 XXX 的 App」就行。它不会直接写代码，而是：
  1. 先问你 5 个问题（谁用 / 要有啥 / 不做什么 / 算成功 / 技术栈）
  2. 给你 2~3 套 UI 风格方向，让你选一套
  3. 出可点击的高保真原型 + 每屏截图，你点开看，说「过」或「哪屏哪里改」
  4. 过审后才开始写代码；每做完一步都停下来等你说「过」

详细用法见压缩包里的「教程4-UI优先开发流程.md」。


常见问题
--------
Q：需要联网吗？
A：不需要。所有文件都在压缩包里，完全离线安装。

Q：提示"无法加载文件，因为在此系统上禁止运行脚本"？
A：说明系统策略拦了。右键「安装.cmd」→「以管理员身份运行」通常可解决；
   还不行就在 PowerShell 里执行一次：
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   然后再双击「安装.cmd」。

Q：杀毒软件报警？
A：安装只是复制文件 + 往几个 .md 文件里插入一段规则文字，不联网、不改注册表。
   可以放行。

Q：会不会覆盖我原来的设置？
A：不会。只"追加"不"替换"：往 AGENTS.md 里加一段，改之前自动备份为
   AGENTS.md.bak-日期时间。技能是新增一个文件夹。

Q：以后规范更新了怎么办？
A：重新拿一份新的压缩包，再双击一次「安装.cmd」即可；重复安装是安全的
   （同一条不会插两遍）。

Q：想卸载？
A：删掉这几个文件夹里的 ui-first-dev：
   %USERPROFILE%\.agents\skills\  %USERPROFILE%\.codex\skills\  %USERPROFILE%\.claude\skills\
   再删掉 AGENTS.md / CLAUDE.md 里「## 开发流程红线」那一节。
